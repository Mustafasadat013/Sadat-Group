Setup Instructions

Installation

Install all required dependencies for the React version.

npm install

Start Development Server

Start the Vite development server for React development.

npm run react:dev

Build for Production

Build the React application for production deployment.

npm run react:build

Preview Production Build

Preview the production build locally before deployment.

npm run react:preview
