Customization Options

Background Image

Change the background image to match your branding

// Set custom background StartupConfig.methods.setBackground('/images/sadat-group-hq.jpg');

Welcome Message

Personalize the welcome message for different users

// Set custom welcome message StartupConfig.methods.setWelcomeMessage('Hello, Sayed Mustafa Sadat');

Business Quote

Update the business quote or slogan

// Set custom business quote StartupConfig.methods.setBusinessQuote('Excellence in every business endeavor');

Calendar Event

Set specific calendar events or hide them

// Set custom calendar event StartupConfig.methods.setCalendarEvent('Meeting with Luxe Team – 3:00 PM');

Configuration Guide

Quick Setup

Easy customization through the configuration file

// Edit startup-config.js to customize: // Change background image background: { image: '/images/your-custom-image.jpg' } // Update welcome message welcome: { message: 'Hello, [Your Name]', quote: 'Your business slogan here' } // Modify calendar events calendar: { events: ['Your custom events here'], showProbability: 0.8 }
